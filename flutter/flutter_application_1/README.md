# MobileDev Flutter

Инструкция по запуску, Supabase/Firebase и GitHub Pages находится в [README репозитория](../../README.md).

Без настроек: `flutter run -d chrome`.

С настройками: скопируйте `config.example.json` в `config.local.json`, заполните параметры и выполните `flutter run -d chrome --web-port 8080 --dart-define-from-file=config.local.json`.
